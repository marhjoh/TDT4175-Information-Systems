# TDT4175 - Information systems

## Overview
This repository contains mandatory work and exam related materials for the course **TDT4175 - Information Systems** at **NTNU Trondheim**.

---

## Contents

### 1. Individual Assignment
Contains BPMN modeling exercises and instructions focused on building diagrams, evaluating workflows, and peer-review guidelines.

### 2. Project
Includes project descriptions for implementing Generative AI (GenAI) in teaching processes, focusing on AS-IS and TO-BE models, security considerations, and implementation plans for NTNU.

### 3. Exam
Contains exams and solutions from 2019–2024.
